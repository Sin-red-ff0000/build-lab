### 錬成物ビルドの分岐
v0.24では「錬成物を作った」だけを条件にせず、以下を別々に参照できます。

- 生成済み錬成物
- 実際に消費した錬成物

### 元素ビルドの考え方
元素は「配分」「カード属性」「錬成物」を別々の条件として扱います。火へ点を多く振っただけで全カードが火属性になることはありません。カードへ元素属性を与えるには対応する元素ルーンを設定します。

元素属性は通常のカードタグとは別枠です。そのため元素ルーンを刻んでも、多タグ・混成条件を無条件に満たすことはありません。既存の役割変換・調律・連結・構築規格・ルーン/アルカナとの組み合わせを保ったまま、元素だけを新しい横軸として追加しています。

- 火：攻撃 / 自傷 / 瞬間火力
- 風：連撃 / 位置変更 / 速度
- 水：循環 / 回復 / 状態異常
- 土：防御 / 反撃 / 成長
- エーテル：ルーン / アルカナ / 複合強化

戦闘開始時の元素配分はスナップショットとして固定されます。戦闘外で配分を変更しても進行中の戦闘へ遡って影響しません。元素系特殊個体も単純な「火に水が有利」の属性じゃんけんではなく、敵の行動パターンを増やす試験条件として実装しています。

## v0.21 — 四元素・第五元素と自動錬成（試作）
「デッキ → 元素・錬成」から使用します。初期解放で、旧セーブでは未使用の状態です。
- 火・風・水・土・エーテルに共通12点を配分。戦闘開始時と山札再構築時に自動供給。
- 15レシピから最大8工程を選び、順番を設定。供給時に上から1巡し、各工程を可能な回数まとめて処理。
- 上位工程の次の1回分に必要な手持ち素材を確保してから、下位工程へ進みます。
- 元素・中間材料・錬成物は全てスタック。ターン・再構築で消えず、次の戦闘では初期化。
- 全13生成物（うち粘土・砂塵は加工専用）。自動使用は各素材1ターン1個まで。備蓄なら加工用に保持。
- エーテルは共通配分で供給する第五元素。専用4レシピで遅延・周期を扱い、万能結合・元素代用・再分解はありません。
- 黒曜石等の強化は1回のカード選択へ適用。同じカードの再発動では追加消費せず、強化倍率はその選択の再発動にも適用。
- 材料不足時は在庫を保持。反応を起こすのは供給時だけで、返還された水からその場で再反応は起こりません。
- 戦闘中の錬成設定は固定。戦闘側に新しい操作ボタンはありません。既存の提示操作機能は従来どおり。
- 5構成例、初回加工予測、戦闘中の在庫・起動予定、終了後の使用数・反応数・加工待ちを表示。
- 錬成個別リセットと構成全リセットに対応。アンロック・勝敗記録は保持。
- 効果量と配分点は試作値です。全ビルド間の最適配分・勝率の調整は今後の検討対象です。

### 試し方
1. デッキ画面で「元素・錬成」を開く。
2. 「黒曜石加工」などの構成例を選ぶと有効になります。
3. 初回加工予測を確認し、実験場で普段どおりカードを選ぶ。
4. 実験終了後に反応数・在庫を確認し、配分や工程を調整。

### 検証
既存回帰テストに加え、全レシピ、在庫保持、備蓄、工程優先、遅延・周期、カード再発動、旧セーブ移行、設定保存、リセット、実戦経路を自動検証。
実ブラウザの実行環境がないため、今回の画面はDOM参照・モバイル構造の静的検証までで、実機表示の目視確認は未実施です。

### 次の更新予定
似た効果を持つカード・遺物・プロトコルなどを大改修する予定。
今回は既存コンテンツの大改修は行わず、錬成レシピ・処理・UIを分離しました。
次回は効果の重複、発動条件の違い、ビルド内の役割を比較し、名称や倍率だけ違う選択肢を見直します。

- CSS/JavaScriptのURLに `?v=0.16.0` を付与し、更新時に旧ファイルキャッシュが混在しないよう変更
- WEB上に残った旧セーブをv0.16へ移行
- 各画面の描画を分離し、旧セーブ等で別画面が1つ失敗しても「システム解説」は先に独立して描画
- 解説データが読み込めなかった場合は、空欄ではなく再読み込み案内を表示
- HTTP配信状態で `guides.js` / `guideView.js` が取得できることを確認

## v0.15 — システム解説を一か所へ集約
独立したメイン項目「システム解説」を追加しました。ゲーム内の説明を探し回らなくても、基本戦闘から高度なビルド要素まで1画面から確認できます。

- キャラクター / キャラクタースタイル

各項目には「概要」「設定・確認場所」「解放時期」「重要仕様」「具体例」を掲載。名称・説明文・関連語から検索でき、カテゴリ絞り込みにも対応しています。スマホでは下部ナビに「解説」を追加し、クイックリンクを横スワイプできます。

## v0.14 — 既存要素拡充 + スマホUI強化
今回は新しい大型システムを増やさず、既存ビルド軸とスマホ操作を重点的に拡張しました。

### 既存要素拡充
- カード +30
- 遺物 +14
- 強化プロトコル +8
- アンロック目標 +16

捨て札・連撃・状態異常・耐久/反撃・自傷/瀕死・循環の6軸を各4枚ずつ追加し、さらにスタイル・調律・役割変換・連結・構築規格・複合挙動との橋渡しカードを追加しています。

新しい遺物/プロトコルは、単一軸の底上げだけでなく「捨て札×循環」「連撃×状態異常」「耐久×反撃」「自傷×連撃」など複合ビルドを強く意識した構成です。

## スマホUI v2
760px以下ではv0.13よりさらにスマホ向け操作へ切り替わります。

- 上部の保存/リセットを「操作」メニューへ集約
- キャラクター/スタイルを横スワイプ選択
- デッキ構築中は現在のデッキ欄を上部へ固定
- カードは60件、遺物は48件ずつ段階表示し、長大リストの描画負荷を軽減
- 検索の詳細フィルターに適用条件数表示と「条件クリア」を追加
- 下部ナビにデッキ枚数・未達成目標数・戦闘中表示のバッジを追加
- 実験場では下部ナビ直上に「実験開始 / B1 / B2 / B3」のクイック操作ドックを表示
- 戦闘カードに現在位置を示すページャーを追加
- スマホ戦闘ではカードごとに「使用 / 中央交換 / 再提示」のタッチ専用ボタンを表示
- 390px以下と横画面向けに追加レイアウト調整
- safe-area、横スワイプ、ボトムシート式モーダルは引き続き対応

特に第1ボス撃破後の「中央交換＝ダブルクリック」「再提示＝右クリック」というPC前提操作を、スマホでは明示ボタンで完全に代替しています。
