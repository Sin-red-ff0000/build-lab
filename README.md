# BUILD LAB v0.19

ビルドを組み、敵条件を自由に設定して短時間カード戦闘で検証し、条件達成によって新しい遊び方を横方向にアンロックしていくブラウザゲームのプロトタイプです。

## 起動
`index.html` をブラウザで開いてください。サーバー不要で動作します。





## v0.19 — キャラクター/スタイル/遺物/プロトコル/調律/特殊個体/複合挙動 大規模拡張
既存システムだけを使ってビルドの枝分かれと敵側の試験条件を大幅に増やしました。新しい大型システムは追加していません。

### キャラクター +8（総19体）
- ノード：カード調律・役割変換
- シンセ：多タグ・混成
- トレーサー：特殊個体・複合挙動
- リズム：提示位置の切替
- ギア：カード連結・循環
- バルワーク：耐久・反撃
- パレット：複数状態異常
- ミラー：同名反復・変奏

各キャラクターはレベル育成なし。対応アンロック目標を達成すれば完成性能で即使用できます。

### キャラクタースタイル +24（総38種）
新キャラ8体に3派生ずつ追加。原型への上乗せではなく、これまで通り固有能力を置き換える方式です。
- ノード：純調律 / 純変成 / 二重校正
- シンセ：三相合成 / 単相濃縮 / 架橋合成
- トレーサー：個体追跡 / 異相追跡 / 無垢試験
- リズム：転拍 / 正拍 / 翼拍
- ギア：継電 / 輪転 / 継電輪転
- バルワーク：迎撃 / 城塞 / 背水城塞
- パレット：毒彩 / 火彩 / 多彩
- ミラー：反復鏡 / 変奏鏡 / 複写鏡

### 遺物 +40（総275種）
調律、役割変換、キャラスタイル、特殊個体、複合挙動、提示位置、反復、連結、循環、捨て札、瀕死、耐久、状態異常、構築規格などを横断する遺物を追加。

### 強化プロトコル +20（総98種）
調律/変換特化、特殊個体/複合挙動対策、提示位置、連結、循環、混成、単独/重複構築などのプロトコルを追加。

### カード調律 +12（総24種）
残響 / 再起 / 症状 / 変成 / 異相 / 個体 / 混成 / 単相 / 広域 / 狭域 / 鍛造 / 転位を追加。
システム解説にも全24種を自動反映し、新調律には「向いている使い方 / 注意点」を追加しています。

### 特殊個体 +12（総53種）
鉄心 / 猛攻 / 残像 / 変異 / 生体要塞 / 報復 / 幽影 / 疫走 / 絶対 / 超浄化 / 高速再生 / 極限を追加。
既存と同じく戦闘内容ではなく敵ステータス条件で発見され、解放後は他の特殊個体と自由に組み合わせられます。

### 複合挙動 +20（総36種）
新特殊個体と既存特殊個体の組み合わせに20種類の専用挙動を追加。追加行動、障壁、再生連動、浄化、低HP変化など、単なる数値加算ではなく戦い方そのものが変化します。

### アンロック
- 新キャラ8件
- 新キャラのスタイル研究8件（各3スタイル）
- 新調律研究6件（各2調律）
- 新特殊個体攻略10件
- 新複合挙動20種ぶんの発見目標も既存の動的アンロック一覧へ自動追加
- 総アンロック目標：365件

## v0.18 — リセット機能拡張 + 既存要素拡充
ビルド実験を繰り返しやすくするため、アンロック進行を消さずに現在の構成だけを初期化できるリセット機能を追加しました。

### リセット機能
- デッキ：現在の構築規格を維持したまま、規格に合う基本デッキへ戻す
- 遺物：装備中の遺物をすべて解除
- 強化プロトコル：選択中プロトコルを解除
- カード調律：設定中の調律をすべて解除
- 役割変換：設定中の役割変換をすべて解除
- カード連結：連結ペアと連結方式を初期状態へ戻す
- 構築規格：標準規格へ戻し、デッキも標準10枚へ戻す
- キャラクター：初期キャラへ戻す
- キャラクタースタイル：現在キャラを原型へ戻す
- 実験場：敵ステータス・特殊個体設定を初期値へ戻す
- 「構成を全リセット」：上記の現在構成をまとめて初期化。アンロック、勝敗記録、ボス進行は保持
- 「全データ初期化」：アンロックを含む全セーブデータを初期化。従来の進行リセットを明確化

### 既存要素拡充
- カード +24（総455種）
- 遺物 +12（総235種）
- 強化プロトコル +6（総78種）
- アンロック目標 +12（総301件）
- 6基本軸の「研究 V」を追加
- スタイル / 調律 / 役割変換 / 連結 / 構築規格 / 複合挙動への橋渡しカード・遺物を追加

## v0.16 — 解説詳細化 + WEB版の説明表示修正
「名前は見えるが、実際に何をする要素なのか分かりにくい」状態を減らすため、システム解説を詳細リファレンス化しました。

### 解説の詳細化
- システム解説を21項目へ拡張
- カード調律12種をすべて個別表示
  - 効果
  - 向いている使い方
  - 注意点
- カード役割変換7種も同じ形式で個別解説
- 連結方式4種、構築規格6種、キャラクタースタイル14種を実データから自動一覧化
- 強化プロトコル、特殊個体、複合挙動も「システム解説」から一覧確認可能
- 「複数システムを同じカードへ重ねた時」の解説を追加
- 解説検索は個別項目名・効果・タグ・使い方向け説明まで検索対象
- 「過負荷調律」のような個別名で検索した場合、該当詳細を自動で開く

### WEB版修正
GitHub PagesなどWEB公開時だけ解説が表示されないケースを対策しました。
- CSS/JavaScriptのURLに `?v=0.16.0` を付与し、更新時に旧ファイルキャッシュが混在しないよう変更
- WEB上に残った旧セーブをv0.16へ移行
- 各画面の描画を分離し、旧セーブ等で別画面が1つ失敗しても「システム解説」は先に独立して描画
- 解説データが読み込めなかった場合は、空欄ではなく再読み込み案内を表示
- HTTP配信状態で `guides.js` / `guideView.js` が取得できることを確認

## スマホUI v2
760px以下ではv0.13よりさらにスマホ向け操作へ切り替わります。

- 上部の保存/リセットを「操作」メニューへ集約
- キャラクター/スタイルを横スワイプ選択
- デッキ構築中は現在のデッキ欄を上部へ固定
- カードは60件、遺物は48件ずつ段階表示し、長大リストの描画負荷を軽減
- 検索の詳細フィルターに適用条件数表示と「条件クリア」を追加
- 下部ナビにデッキ枚数・未達成目標数・戦闘中表示のバッジを追加
- 実験場では下部ナビ直上に「実験開始 / B1 / B2 / B3」のクイック操作ドックを表示
- 戦闘カードに現在位置を示すページャーを追加
- スマホ戦闘ではカードごとに「使用 / 中央交換 / 再提示」のタッチ専用ボタンを表示
- 390px以下と横画面向けに追加レイアウト調整
- safe-area、横スワイプ、ボトムシート式モーダルは引き続き対応

特に第1ボス撃破後の「中央交換＝ダブルクリック」「再提示＝右クリック」というPC前提操作を、スマホでは明示ボタンで完全に代替しています。
