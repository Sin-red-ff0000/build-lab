# BUILD LAB v0.75

BUILD LABは、レベル上げや素材収集の縦成長ではなく、無料で組み替えられる横方向のビルド研究を中心にした実験型ローグライク・カードバトルです。

## v0.75 正式リリースの要点

v0.36以降の大規模改修ロードマップと最終全件監査を統合した正式版です。

- 49キャラクター / 128スタイル、原型込み177構成。
- カード679種を中心に、下位互換・数字違い・役割圧縮・未使用候補を大規模再設計。
- 消失 / 復帰 / 非選択 / 提示中 / 記録 / 予約 / 変質などの共通イベント系メカニクスを追加。
- 二面カードを拡張し、「表→裏＝単純強化」ではなく役割転換を重視。
- 遺物507 / プロトコル175 / 調律82を横断監査し、巨大倍率依存を抑制。
- 毒 / 火傷 / 出血 / 凍傷を個別の状態異常カテゴリとして扱い、凍傷は短期的な敵ターン抑制へ再設計。
- 章進行を「新要素を理解してボスを攻略する」カリキュラム型へ再校正。
- 旧HP×12等の単一数値試験を通常進行から分離し、8種類の公式エンドコンテンツ校正へ再構築。
- 177/177構成すべてに最低1つの公式校正で実戦勝利経路を確認。
- 最終全件監査PASS。消耗校正は長期戦として60ターン局所監査を行い、完成阻害級4条件をすべて解消。
