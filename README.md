# BUILD LAB v0.36

## v0.36 — 全スタイル終盤校正 / 章進行再設計 / 表示版数統一

- 40キャラクター＋101スタイル、原型込み141構成をエンドコンテンツ検証。
- HP×12 / 攻撃×10 / 防御×10 / 速度×4の同時条件を、各構成のコンセプトを使って撃破可能に校正。
- 基礎6軸に各カード6＋遺物6、追加8軸にも各カード6＋遺物6を保証。
- 初期無料プールを35カード / 18遺物へ再設計し、旧無料枠を章内アンロック報酬へ再配置。
- 極端試験を第3ボス後、全域校正を第4ボス後のエンドコンテンツへ移動。
- 第2〜第4章は、その章で解放されたシステムを運用することで突破率が大きく上がるよう再校正。
- 画面上に残っていた `PROTOTYPE 0.26` を修正。バージョン表示・タイトル・セーブキーを `js/version.js` の単一定義から取得。
- セーブキーは `build_lab_proto_v36`。v0.32以前を移行対象として保持。


BUILD LABは、レベル上げや素材収集の縦成長ではなく、無料で組み替えられる横方向のビルド研究を中心にした実験型ゲームです。

## v0.31〜v0.32の主な追加
- 第2段階を維持する意味がある「選択成長」カード6種を追加。
- 第2段階から条件によって異なる最終形へ固定分岐する「分岐成長」カード6種を追加。
- 分岐はカード実体（UID）単位。別の同名カードへ伝播せず、一度確定した枝は条件が変わっても乗り換えません。
- 選択成長・分岐成長向け遺物 / プロトコル / 調律を追加。
- 戦闘画面に成長段階・成長方針・確定分岐を表示。
- Windows版回帰スクリプトにv0.30〜v0.32専用テストを追加。
- 更新ZIPの用途を「ローカル上書き用」と「GitHub直下用」に分離。
