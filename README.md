# BUILD LAB v0.15

ビルドを組み、敵条件を自由に設定して短時間カード戦闘で検証し、条件達成によって新しい遊び方を横方向にアンロックしていくブラウザゲームのプロトタイプです。

## 起動
`index.html` をブラウザで開いてください。サーバー不要で動作します。


## v0.15 — システム解説を一か所へ集約
独立したメイン項目「システム解説」を追加しました。ゲーム内の説明を探し回らなくても、基本戦闘から高度なビルド要素まで1画面から確認できます。

### 収録内容
- 基本戦闘 / 提示操作 / セーブ・中断再開
- キャラクター / キャラクタースタイル
- デッキ / 遺物 / 強化プロトコル
- カード調律 / カード役割変換
- カード連結 / 連結方式 / 構築規格
- 敵ステータス / 特殊個体 / 複合挙動
- アンロック / ボス / 検索 / スマホ操作

各項目には「概要」「設定・確認場所」「解放時期」「重要仕様」「具体例」を掲載。名称・説明文・関連語から検索でき、カテゴリ絞り込みにも対応しています。スマホでは下部ナビに「解説」を追加し、クイックリンクを横スワイプできます。

## v0.14 — 既存要素拡充 + スマホUI強化
今回は新しい大型システムを増やさず、既存ビルド軸とスマホ操作を重点的に拡張しました。

### 既存要素拡充
- カード +30
- 遺物 +14
- 強化プロトコル +8
- アンロック目標 +16

捨て札・連撃・状態異常・耐久/反撃・自傷/瀕死・循環の6軸を各4枚ずつ追加し、さらにスタイル・調律・役割変換・連結・構築規格・複合挙動との橋渡しカードを追加しています。

新しい遺物/プロトコルは、単一軸の底上げだけでなく「捨て札×循環」「連撃×状態異常」「耐久×反撃」「自傷×連撃」など複合ビルドを強く意識した構成です。

## スマホUI v2
760px以下ではv0.13よりさらにスマホ向け操作へ切り替わります。

- 上部の保存/リセットを「操作」メニューへ集約
- キャラクター/スタイルを横スワイプ選択
- デッキ構築中は現在のデッキ欄を上部へ固定
- カードは60件、遺物は48件ずつ段階表示し、長大リストの描画負荷を軽減
- 検索の詳細フィルターに適用条件数表示と「条件クリア」を追加
- 下部ナビにデッキ枚数・未達成目標数・戦闘中表示のバッジを追加
- 実験場では下部ナビ直上に「実験開始 / B1 / B2 / B3」のクイック操作ドックを表示
- 戦闘カードに現在位置を示すページャーを追加
- スマホ戦闘ではカードごとに「使用 / 中央交換 / 再提示」のタッチ専用ボタンを表示
- 390px以下と横画面向けに追加レイアウト調整
- safe-area、横スワイプ、ボトムシート式モーダルは引き続き対応

特に第1ボス撃破後の「中央交換＝ダブルクリック」「再提示＝右クリック」というPC前提操作を、スマホでは明示ボタンで完全に代替しています。
